# Security Policy

## Supported Versions

| Version | Supported |
|---------|-----------|
| 1.0.x   | ✅ Current |
| 0.x     | ❌ End of life |

## Reporting a Vulnerability

Do **not** open a public GitHub issue for security vulnerabilities.

Use GitHub Security Advisories to report privately:
`https://github.com/opensecstack/nis2compass/security/advisories/new`

Include in your report:
- Description of the vulnerability
- Affected version(s)
- Steps to reproduce
- Potential impact
- Any suggested fix (optional)

## Response SLA

| Severity | Acknowledgement | Patch |
|----------|----------------|-------|
| CRITICAL | 24 hours | 7 days |
| HIGH | 48 hours | 14 days |
| MEDIUM | 72 hours | 30 days |
| LOW | 5 business days | Next release |

## Safe Harbour

We will not pursue legal action against researchers who report vulnerabilities in good faith under this policy, provided they do not access or modify data beyond what is required to demonstrate the vulnerability, and do not disclose the vulnerability publicly before a fix is available.

## PGP Key

Security reports may be encrypted using the opensecstack security team PGP key published at `https://opensecstack.org/security.asc`.
