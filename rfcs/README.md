# opensecstack RFCs

Request for Comments (RFCs) for significant changes to the opensecstack ecosystem.

## When to Write an RFC

- New platform addition
- Breaking changes to SDK contracts
- Cross-platform architectural changes
- New integration patterns
- Plugin system design (RFC-0001)

## RFC Process

1. Copy `0000-template.md` to `0000-my-proposal.md`
2. Fill in the template
3. Open a PR with the RFC
4. Discussion happens in the PR
5. Core maintainers approve or request changes
6. Approved RFCs are merged and assigned a number
