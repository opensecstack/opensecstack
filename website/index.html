Core Platforms

Everything your team needs to secure and comply

Three active platforms, five more on the roadmap — all sharing the same SDK contracts and governed by the same immutable audit chain.

APIGuard

Point APIGuard at any OpenAPI, Swagger, or GraphQL schema and get a full OWASP API Security Top 10 report automatically. CVSS 3.1 scoring, SARIF output, and one-line CI/CD integration.

OWASP A1–A10 CVSS 3.1 SARIF Go + Rust Apache 2.0

NIS2 Compass

NIS2 Article 21(2) compliance management from gap assessment to signed PDF evidence. Tracks all 10 measures, manages evidence artifacts, and generates audit-ready reports.

NIS2 Art. 21(2) Evidence Vault PDF Reports Python + Flask AGPL-3.0

CITADEL

The governance engine. MARSHAL evaluates every privileged action through 5 deterministic gates. Every outcome is written to an append-only, SHA-256 hash-chained WORM log with Ed25519 notary anchoring.

MARSHAL 5-Gate WORM Log SHA-256 Chain SoD Enforcement AGPL-3.0
Getting to Compliance

Three steps from zero to audit-ready

opensecstack is designed to get you to demonstrable NIS2 compliance with as little friction as possible.

1

Connect your APIs

Point APIGuard at your OpenAPI spec and a running target. Within minutes you have a complete OWASP API Top 10 assessment — BOLA, broken authentication, SSRF, security misconfiguration, and more — with CVSS 3.1 scores and actionable remediation guidance.

2

Run security scans

Every scan result is submitted to CITADEL as a Kerkese evidence payload. MARSHAL evaluates authority, scope, and evidence completeness through 5 gates before the result is appended to the tamper-evident WORM log. Findings above a configured severity threshold automatically trigger an NIS2 Compass control update.

3

Generate compliance reports

NIS2 Compass maps your evidence to all 10 Article 21(2) measures and generates a signed PDF compliance report. Because every evidence item is cryptographically linked to the CITADEL WORM chain, the report is verifiable end-to-end — from raw scan result to compliance assertion.

Architecture

One governance layer, every platform

All platforms share the same SDK contracts and emit governance events to the same CITADEL chain. No platform can bypass governance without the failure being visible.

Quickstart

Up and running in minutes

The full ecosystem runs on Docker Compose. No cloud account, no sign-up, no telemetry. 

# Clone the repository
git clone https://github.com/opensecstack/opensecstack
cd opensecstack

# Set required secrets
cp deploy/.env.example deploy/.env
# Edit deploy/.env — set POSTGRES_PASSWORD, JWT secrets, etc.

# Start the full stack
docker compose -f deploy/docker-compose.yml up -d

# Run your first API security scan
apiguard scan --spec ./api/openapi.yaml \
              --target http://localhost:8080 \
              --format html

Requires Docker >= 24 and Docker Compose v2. See the Quick Start guide for Kubernetes manifests and per-platform setup.
